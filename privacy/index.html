Privacy

What this site collects about you: nothing

The Grants Ledger is a static website — plain files served over the web, built from public IRS filings. It has no accounts, no login, no forms, no cookies, and the one analytics script it loads is a cookie-free page counter that records no personal data. This page describes the actual data flows, checked against the site’s own code, so that a reviewer can check the claim rather than take it.

Effective 31 August 2026 · checked against the published source on that date

The short version

I receive nothing that identifies you. A page counter tells me, in aggregate, whether a page is being read — never who read it.

—
Accounts, logins, sign-ups
None exist. There is nothing on this site to register for.
—
Forms of any kind
There is not a single <form> element on the site. Nothing collects a name, an email address, or any other input.
—
Cookies
This site sets no cookies. It never reads or writes document.cookie.
●
Analytics: a cookie-free page counter
Every page loads a small script from GoatCounter ↗ that counts page views without cookies or personal data. Details below. No other analytics or tracking script of any kind runs here — no Google Analytics, no tag manager, no Plausible, Fathom, Matomo, Hotjar, Segment, Mixpanel or PostHog. No tracking pixel, no beacon, no session recording.
—
Advertising or data sales
There is no advertising on this site and no data about visitors to sell, share or transfer, because none is gathered.
—
Fingerprinting or cross-site tracking
None. The referrer policy on every page is strict-origin-when-cross-origin, so the pages you view are not passed along in full to other sites.
●
Saved lists and notes
Stored in your own browser only, and never sent anywhere. Details below.
●
Ordinary web-server request logs
Kept by the hosting provider, as with any website. Details below.

What is stored in your browser

The collection page lets you save foundations and recipients to a list and attach your own notes to them. That is the only feature on the site that remembers anything, and it remembers it on your device.

Stored valueWhereWhat it holdsLeaves your browser?
gl_listbrowser localStorageThe identifiers of the foundations and recipients you saved to your list.No. Never transmitted.
gl_notesbrowser localStorageThe notes you typed against items on your list.No. Never transmitted.

These two values live in your browser’s local storage for this site only. They are not synchronised to any server, not shared between your devices, and not visible to anyone but you. No copy reaches the maintainer of this site at any point.

You can delete them at any time by clearing site data for this domain in your browser settings. They will also be absent in a private window, or in a different browser, or on a different device — which is the ordinary consequence of storing them locally rather than in an account.

Exports — the CSV, spreadsheet and report files the site can produce — are generated inside your browser from data already downloaded to it, and are written directly to your device. Nothing about an export is transmitted or recorded.

Who else necessarily sees your request

Three third parties are involved in serving and measuring these pages. None is a choice made to gather information beyond what is stated below, and all three are named here so a reviewer does not have to discover them by inspecting the page.

GitHub Pages — hosting

The site is served by GitHub Pages, a static file host operated by GitHub, Inc. Every request for a page, image or data file on this site therefore reaches GitHub’s servers, which receive the request in the ordinary way that any web host does — including your IP address, the file requested, the time, and your browser’s user-agent string. Those logs belong to GitHub and are governed by GitHub’s own privacy practices; the maintainer of this site has no access to them and receives no report derived from them.

GoatCounter — a page counter, not a tracker

Every page loads a small script from GoatCounter (gc.zgo.at/count.js), a page-view counter built specifically to avoid personal data. On each page view it records the page path, the referring page, a coarse browser/screen-size category, and the visitor’s country derived from the IP address — GoatCounter does not store the IP address itself. It sets no cookie, cannot tell one visitor’s repeat views from another’s, and does not build a profile of anyone. Its own privacy policy is at goatcounter.com/privacy. This is the sole purpose it serves here: knowing, in aggregate, whether a page is being read.

Google Fonts — the three typefaces

The pages load their typefaces (Fraunces, Newsreader and IBM Plex Mono) from Google’s font service at fonts.googleapis.com and fonts.gstatic.com. Those requests go to Google and, like any web request, carry your IP address and user-agent string. Together with GoatCounter above, these are the only third-party assets on the site; there is no other external script, stylesheet, image, frame or endpoint anywhere on it.

If your organization’s policy is to avoid third-party font requests, this is the single dependency to raise — the fonts can be self-hosted instead. Say so and it will be changed.

Everything else the site loads comes from the site itself. All of its data requests are relative paths to files on this same domain — the collection database, the search index, the map geometry. There is no application programming interface call to any outside service, no content delivery network beyond the host, and no request whose destination is not one of the two above.

Links that leave the site

For completeness: each foundation’s ledger page carries ordinary outbound links to the source record — the foundation’s filings on irs.gov and its entry on ProPublica’s Nonprofit Explorer — so that any figure can be checked against the original. Those are links, not embedded content. Nothing is requested from either site unless you click, and no frame, script, image or pixel is loaded from them at any time.

If you do click, you are on that site under its own policies. Because every page here sets strict-origin-when-cross-origin, what is passed along is this site’s address, not the particular page you were reading.

If you email me

Email is the only way to contact this project, and it is the only circumstance in which the maintainer holds anything about you at all: your email address and whatever you chose to write.

That correspondence is used to answer you and, where you reported an error, to record what was checked and changed. It is not added to a mailing list — no mailing list exists. It is not used for marketing, not shared with anyone, and not sold. If you would like your correspondence deleted, ask, and it will be.

About the people named in the data

This site publishes information from Form 990-PF, the annual return that private foundations file with the Internal Revenue Service and which the IRS makes available for public inspection. The foundations, recipients, amounts, purposes and addresses shown are reproduced from those public documents as filed. Nothing is added to them. No filing is enriched with information from another source about any person, no profile of any individual is constructed, and no attempt is made to identify anyone.

Grants to individuals are handled differently from grants to organizations. Some foundations report scholarships, fellowships, educational loans and hardship grants paid to named people — students, patients, families, sometimes minors. Those rows are part of the public return, and their amount, year, purpose and state are published exactly as filed, so every year of that page still adds up to the total the foundation reported. What is withheld is the name, and only the name — everywhere the site publishes. A row that names an individual reads Individual recipient (name withheld) on the foundation’s own ledger page, its printed report and its CSV export; in the site-wide search, the cross-foundation recipient profiles, the bulk export and the data files behind the pages it carries the placeholder [INDIVIDUAL RECIPIENT - WITHHELD FROM INDEX]. Either way the recipient’s city is blanked too, so the row cannot be re-identified by location. At the last build this applied to 33,982 rows across 319 foundations. The rule that decides which rows these are is published in the source code and combines the filer’s own choice of the person-name field on the return with a test of the name and the stated purpose; it is deliberately conservative, and a real organization occasionally falls on the individual side of it.

If you are named in a filing reproduced here and want the row removed from the ledger page as well, write. It will be taken down while it is looked at against the original filing, and it will not be restored without a reason being given to you.

What is deliberately not claimed here

A trust page is worth less than nothing if it promises a regime that has not been implemented. These are the honest boundaries.

—
No compliance certification
This project holds no SOC 2 report, no ISO 27001 certificate, and no third-party security audit. None has been performed. The security posture is that of a static site with no server, no database, no user accounts and no stored personal data.
—
No formal GDPR or CCPA program
No data-protection officer, representative, or formal request-handling process has been appointed or built. What is true instead is that the site collects no personal data, so there is no store of it to access, port or erase. Correspondence you send by email is the sole exception, and it is deleted on request.
—
No data-processing agreement is offered today
Because no visitor data is processed, none has been drafted. If your organization requires one before using this site, raise it and it will be worked through rather than waved away.
—
No cookie banner, because there is nothing to consent to
The absence of a banner here is not an oversight. The site sets no cookies and runs no tracking, so there is no consent to collect.

Changes to this notice

This notice is dated. If the site ever gains something that changes the answer above — analytics, a form, an account system, a hosted service — this page will be updated before that change ships, and the change will be recorded in the update history so the difference is visible rather than silent.
