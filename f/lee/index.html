        The referee

        Halt-on-fail: a year publishes only when it reconciles exactly

        Grant rows come from the Form 990-PF grants-paid schedule — Part XIV in current filings, formerly Part XV. For every tax year, the sum of the grant rows must equal Part I, line 25, column (d) — charitable disbursements — to the dollar. A year that does not tie is withheld, never estimated. All five available years pass; the same checks re-run in your browser’s console on every load.

        Which filed total this ledger reconciles to

        In this foundation’s returns the grants schedule and Part I line 25(d) are not the same number, so the referee here is stated plainly: the schedule’s own filed total, Part XIV line 3a. Every year’s rows sum to it exactly.

          The purpose map

          “Where a granted dollar goes” assigns each grant to one category by the words of the filing itself — first the filed purpose, then (only when the purpose names no field) the recipient’s filed name. Every rule is published below; anything no rule matches is left unassigned rather than guessed. The filed purpose text on every ledger row remains the record. On this page there is a third step: when the filed purpose names no field and the recipient’s name matches no published rule, the recipient’s own classification in the IRS Business Master File (its NTEE code) is used — accepted only when the filing’s own recipient state pins the name to exactly one organization, when the name is nationally unique, when every same-named listing carries one classification, or when all listings are chapters of a single group exemption. Names with conflicting listings stay unassigned, as do IRS groups with no honest home in these categories.

          Recipient location is the mailing address on the filing, not a service area. Display casing is editorial; hover any name for the as-filed text. Amounts are as filed; no inflation adjustment.
